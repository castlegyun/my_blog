오늘 배운 Git과 GitHub, 정말 재미있었다!

오늘 모두의연구소 아이펠 수업에서는 Git과 GitHub를 배웠습니다. 이름만 들어 봤던 도구였는데, 직접 써 보니 생각보다 훨씬 재미있었어요.

🧠 오늘 배운 핵심

🗂️

Git

내 코드의 변경 이력을 기록하고 되돌릴 수 있게 해 주는 버전 관리 도구.

☁️

GitHub

Git 저장소를 온라인에 올려 백업하고, 다른 사람과 함께 작업하는 공간.

🔁

기본 흐름

add → commit → push 순서로 기록하고 올린다.

⌨️ 직접 해 본 명령어

git init                  # 저장소 만들기
git remote add origin <주소>   # GitHub와 연결
git add .                 # 변경 파일 담기
git commit -m "메시지"     # 기록 남기기
git push -u origin main   # GitHub에 올리기

💬 느낀 점

코드를 저장하는 일이 이렇게 체계적일 수 있다니! 내가 만든 결과물이 GitHub에 올라가고, 이렇게 블로그로 배포까지 되는 게 신기했다.
